## Current research direction

My current work focuses on **reproducible multi-omics integration** for microbiome research. The central methodological problem is ensuring that Joint-RPCA workflows implemented in different software ecosystems are compared using equivalent inputs, preprocessing rules, model settings, and validation criteria.

### Joint-RPCA and microbiome analytics

The work includes:

- comparing R/Bioconductor and Python/Gemelli implementations;
- developing and testing input-filtering behavior for biological count data;
- validating sample and feature representations after alignment;
- documenting cross-language workflows with fixed configuration and reproducible outputs;
- examining how preprocessing choices affect downstream interpretation.

Relevant repositories:

- [`Joint_RPCA_in_R`](https://github.com/sabujcb/Joint_RPCA_in_R) — reproducible R implementation and R–Python comparison workflow
- [`mia_JRPCA`](https://github.com/sabujcb/mia_JRPCA) — development work based on the Bioconductor `mia` package
- [`OMAWorkflows`](https://github.com/sabujcb/OMAWorkflows) — reproducible workflow and documentation work

These repositories contain active research and development work; they should not be interpreted as peer-reviewed software releases unless explicitly stated in the repositories.
